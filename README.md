# Mohamed Hussien — Cybersecurity Portfolio

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Before publishing
Replace these placeholders in `index.html`:
- `YOUR_EMAIL@example.com`
- LinkedIn URL
- GitHub URL
- Upwork URL

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. In the repository, open **Settings → Pages**.
4. Select the main branch as the deployment source.
5. Save and wait for the Pages URL.

The portfolio intentionally describes lab/training experience rather than claiming professional cybersecurity employment.
